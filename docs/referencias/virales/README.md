# Biblioteca de virales

Fichas de los virales que usamos como vara. **juez-viral** compara cada guion nuestro contra estas fichas, parte por parte (gancho, medio, final). Ningún guion le llega a Tomás si no les gana (regla del guion, `docs/GUIONISTA.md` §0).

- **estado: con /watch** → la ficha se hizo mirando el video con `tools/watch/watch.py` (cuadros + transcripción).
- **estado: sin /watch** → armada con las investigaciones; lo que dice "por ver" no se sabe y no se inventa. Se completa cuando Tomás mande la grabación.
- Los videos fuente no se guardan en el repo (son de otros). Sólo la ficha y, como mucho, `img/<slug>/hook.jpg` y una hoja de cuadros comprimida.
- Cada video nuevo que mande Tomás entra con la skill `watch`.
